Privacy

This page describes the RunSpecimen product and this marketing site. It does not invent account, analytics, or compliance claims.

The RunSpecimen CLI

  • Runs locally in your workspace.
  • Does not phone home and ships with no product telemetry.
  • Does not require a RunSpecimen account or cloud control plane in the current release candidate.
  • Stores approval, state, event logs, captures, and certificates under your workspace (typically .runspecimen/).
  • The optional dashboard binds only to 127.0.0.1, is read-only, and has no remote service.

This website

runspecimen.darashkevich.com is a static marketing site. It does not offer user accounts or an on-site contact form. Your browser and network path (including any CDN or DNS provider in front of the site) may process standard request metadata such as IP address and User-Agent as part of serving pages — that is infrastructure behavior, not RunSpecimen product telemetry.

Third-party services you choose

If you visit linked third-party sites (for example GitHub documentation or issues), those services apply their own privacy practices. Marketplace adapters, when listed, are install surfaces only; they are not the enforcement boundary and do not change the local-only nature of the CLI.

Contact

Privacy questions about this site or the open-source project can be raised via Support channels (GitHub issues for non-sensitive topics).
