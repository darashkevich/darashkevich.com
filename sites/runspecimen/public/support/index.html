Bugs and product questions

Open an issue on github.com/darashkevich/runspecimen. Include the RunSpecimen version, Python version, OS, and the relevant command when you can.

Interrupted runs and incidents

Use runspecimen recovery-status to determine whether a run was interrupted. Abandonment is an audited, real-TTY decision; the old run ID remains permanently terminal. Do not remove state files or assume recovery makes an untrusted payload safe. For a reconstructable local pack, runspecimen bundle copies run evidence without pairing tokens or Mac challenge secrets. That pack is not a hosted vault.

Security reports

RunSpecimen is an orchestration and evidence layer, not an OS sandbox. For a suspected vulnerability, do not include secrets, private receipts, or proprietary contracts in a public report. Provide a minimal reproduction and keep the report private to the maintainers of the distribution you received, until a dedicated private reporting address is published. See SECURITY.md.
